# All-database-Scraper

Kumpulan Scraper, AI Client, dan Modul Bot oleh **FallEzz (FallZx Infinity)**.
Setiap fitur dipisahkan ke dalam masing-masing folder agar rapi dan mudah dicari.

---

## 📂 Struktur Folder

| Folder | Isi File | Deskripsi |
| :--- | :--- | :--- |
| 📁 [`archive-music-scraper/`](./archive-music-scraper) | `archive_music_client.js` | Scraper & Downloader musik dari **Internet Archive** (`searchMusic`, `getArtist`, `downloadMusic` MP3). |
| 📁 [`cantarella-ai-nodejs/`](./cantarella-ai-nodejs) | `chatbot.js`, `server.js` | Client & Web Server **Cantarella - Ai** versi **Node.js** (Multi-Provider: OpenRouter Venice, Groq, Pollinations AI). |
| 📁 [`cantarella-ai-python/`](./cantarella-ai-python) | `chatbot.py`, `app.py` | Client & Web Server **Cantarella - Ai** versi **Python** (Multi-Provider: OpenRouter Venice, Groq, Pollinations AI). |
| 📁 [`whatsapp-autoai-pv/`](./whatsapp-autoai-pv) | `autoai_pv.js` | Modul **Auto-AI Private Chat (DM)** untuk Bot WhatsApp dengan persona **Cantarella - Ai** menggunakan Pollinations AI. |
| 📁 [`quran-nu-scraper/`](./quran-nu-scraper) | `quran_nu_scraper.js` | Scraper lengkap **Quran NU Online** (`https://quran.nu.or.id/`): **Surah, Juz, Urutan Turun, Tahlil, Doa, Wirid, Maulid, Hadits, & Jadwal Sholat**. |
| 📁 [`jkt48-scraper/`](./jkt48-scraper) | `jkt48_scraper.js` | Scraper lengkap **JKT48 Official** (`https://jkt48.com/`): **Member Aktif/Ex, Detail Profil & Jikoshoukai, News, Jadwal Teater, Kalender Event, Setlist, & Now Live (IDN/Showroom)**. |
| 📁 [`shazam-scraper/`](./shazam-scraper) | `shazam_scraper.js` | Scraper & Downloader **Shazam / Apple Music Catalog** (`https://www.shazam.com/`): **Search Lagu & Artis, Detail Lagu + Lirik (Plain & Synced LRC), Profil Artis & Album, Top Charts Negara, & Download Audio Preview (.m4a)**. |
